# つみきドロップ

ぴよまるといっしょに、ブロックをそろえて消そう。

8BitDo Lite 2 などのゲームコントローラーであそべる、オリジナルの落ちものパズルです。キーボードやスマホのタッチでもあそべます。

- 落ちてくるブロックを動かしてまわし、横一列をそろえると消えます。4列いっぺんに消す「よんれつ！」で、ひよこのぴよまるが大よろこびして紙ふぶきが舞います。
- 続けて消すと「れんさ」、Tブロックをくるっと入れる「Tスピン」、盤面をからっぽにする「ぜんけし」でボーナス。
- 7種類が1回ずつ出る袋式の順番、ゴースト（落ちる位置の影）、ホールド、NEXT表示、壁けり回転、着地のあそび時間があります。
- 10ラインごとにレベルが上がって速くなり、空の色も変わります。ベストスコアはブラウザに保存されます。
- 音はWebAudioで作ったピコピコ音で、初期設定はオフです（効果音とBGMは別々にオンにできます）。
- 外部ファイルやネットワーク接続は使いません。

## コントローラー（8BitDo Lite 2）

Bluetooth か USB でつなぎ、ボタンを1回押すと「コントローラー接続中」と表示されます（ブラウザによっては、押すまで認識されません）。

| ボタン | 動き |
|---|---|
| 十字 ← → | いどう（長押しで連続） |
| 十字 ↓ | ゆっくりおとす |
| 十字 ↑ | すとんとおとす |
| A（右） | 右にまわす |
| B（下） | 左にまわす |
| Y（左） | はんかいてん |
| X・L・R | ホールド |
| Start | ひとやすみ |
| Select | メニュー／やりなおし |

十字キーがボタン扱い・スティック扱い・ハット軸扱いのどのモードでも動きます。「？」の画面で、押したボタンの番号を確かめられます。回転の向きは入れかえできます。

## キーボード

← → ↓：いどう・ゆっくり ／ Space：すとん ／ ↑・X：右回転 ／ Z・Ctrl：左回転 ／ A：はんかいてん ／ C・Shift：ホールド ／ Esc・P：ひとやすみ ／ M：効果音

iPhoneではSafariで開き「共有」→「ホーム画面に追加」で全画面表示になります。
